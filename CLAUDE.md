# Karteek Clone — code

This repository holds only code: the proactive check-in runner, the workflow-catalog importer, and their tests. All knowledge (operating instructions, identity, memory, sources, workflows, templates, private material) lives in the Obsidian vault named by `KARTEEK_VAULT` in `.env`. Read the vault's `AGENTS.md` before acting on Karteek's behalf; this repo's own conventions are in [README.md](README.md). Never copy vault content into this repo.
